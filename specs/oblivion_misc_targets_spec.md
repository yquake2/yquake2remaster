# Functional Specification: Oblivion Misc Targets & Teleporters

## 1. Overview
This specification covers Oblivion miscellaneous environmental and target entities:
- `info_teleporter_dest`
- `misc_screenfader`
- `target_rocket`
- `target_railgun`

---

## 2. Implementation & Behavior
- **Teleporter Destination:** Defines custom teleport arrival points (`info_teleporter_dest`).
- **Screen Fader:** Manages client screen fading visual effects (`misc_screenfader`).
- **Target Projectiles:** `target_rocket` and `target_railgun` fire targeted projectiles or rail traces when triggered by game logic.
